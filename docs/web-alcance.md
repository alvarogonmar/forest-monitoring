# Website and Administrative Dashboard

Public website for exploring predefined forest routes and a private
administrative dashboard for viewing sensor locations, detection counts,
and received help requests.

This component communicates with the shared backend. Public route responses
must not expose private sensor or help-request data.

The website uses React with JavaScript (JSX). The proposed setup is Vite,
React Router, CSS/CSS Modules, and Leaflet with React Leaflet.
See [the complete project structure](../estructura_proyecto.md) for
pages, API contracts, and access rules.
Setup and run instructions will be added when implementation begins.
